# SQLite extension release notes

## [1.0.0](https://github.com/abu-abbas/kilat/releases/tag/ext-sqlite-1.0.0) · 2026-11-23

Minimum Kilat version `0.1.52`.

- First signed SQLite package for installation from Settings → Extensions.
- Open local SQLite files, browse tables and run SQL. Edit data when the connection allows writes.
